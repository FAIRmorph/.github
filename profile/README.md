# FAIRmorph — Making ecological data FAIR shouldn't be this complicated.

**FAIRmorph** is an open-source, local-first project helping ecological researchers and data stewards **combine, clean, describe and check research data**—making it easier for others to understand and reuse.

Our goal is a **guided, no-code desktop workflow** with ecology-specific questions, transparent scientific documentation, **versioned decisions** and **verifiable, repeatable processing**.

FAIRmorph aims to make the entire data preparation process easier, while supporting established standards such as Darwin Core and repositories such as PANGAEA.

> **Prototype Fund (Germany) · Proof of concept — not production software.** The current prototype demonstrates the technical foundation. Complete guided workflows and general-purpose publishing remain under development.
