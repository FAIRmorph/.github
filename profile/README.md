# FAIRmorph — Making ecological data FAIR shouldn't be this complicated.

**FAIRmorph** is an open-source, local-first project helping ecological researchers and data stewards **combine, clean, describe and check research data** so others can understand and reuse them.

Our goal is a **guided, no-code desktop workflow** with ecology-specific questions, clear scientific documentation, **versioned decisions** and **verifiable, repeatable processing**. Well-prepared data can also support standards such as **Darwin Core** and preparation for repositories such as **PANGAEA**.

> **Prototype Fund (Germany) proof of concept — not production software.** The Engine, desktop Workbench and real-data validation demonstrate the technical foundation; complete guided workflows and general-purpose publishing remain in development.

### Repositories

- **[Engine](https://github.com/FAIRmorph/fairmorph-engine)** — Python data processing, source preservation, review records and verified runs.
- **[Workbench](https://github.com/FAIRmorph/fairmorph-workbench)** — local desktop interface built with Tauri.
- **[Validations](https://github.com/FAIRmorph/fairmorph-validations)** — reproducible tests using real ecological research data.
- **[Website & documentation](https://github.com/FAIRmorph/fairmorph.org)** — project overview, concept and technical guides.
